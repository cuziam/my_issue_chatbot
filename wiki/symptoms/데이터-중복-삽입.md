## 조사 시 체크포인트
1. 패치 적용 후 의도하지 않은 테이블의 insert 주기가 변경되었는지 DB에서 time 컬럼 기준으로 확인
2. insert SQL에 NOT EXISTS 등 중복 방지 조건이 유지되고 있는지 확인
3. 코드 레벨에서 checkExist* 류 중복 체크 메서드가 패치 과정에서 제거/변경되지 않았는지 확인
4. 테이블 행 수가 비정상적으로 증가했다면 truncate 후 정상 동작 여부 확인
5. 패치로 추가된 기능(신규 테이블)과 기존 테이블의 insert 로직이 서로 독립적으로 동작하는지 확인
