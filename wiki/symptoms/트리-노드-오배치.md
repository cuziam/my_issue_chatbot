## 조사 시 체크포인트
1. 트리 그리드에서 서로 다른 엔티티(그룹/하위그룹 등)의 ID가 동일 컬럼에 저장되는지 확인
2. `findNode`/`searchNode`가 DFS로 첫 번째 매칭을 반환하는지 확인 — ID 충돌 시 잘못된 노드 반환 가능
3. 독립 시퀀스에서 생성된 ID 간 숫자 중복 여부 확인 (예: XAPM_GROUP_INFO vs XAPM_SUB_GROUP_INFO)
4. 트리 빌드 시 부모 노드 참조를 전역 검색이 아닌 Map/직접 참조로 관리하는지 확인
5. 업그레이드(플랫 그리드 → 트리 그리드) 후 기존 데이터에서 ID 충돌이 발생하는 환경이 있는지 확인
