## 조사 시 체크포인트
1. 해당 화면에서 표시하는 칼럼이 별도 등록/설정이 필요한 메타데이터인지 확인 (업무 등록, 거래 분류 등)
2. DB 테이블에서 해당 필드의 ID가 0 또는 NULL인 레코드가 있는지 확인 (BUSINESS_ID=0 등)
3. 프론트엔드에서 ID→이름 변환 시 캐시(Comm.etoeBizInfos 등)에 해당 ID가 존재하는지 확인
4. 업무 등록 후 삭제한 이력이 있는지 고객사에 확인 (삭제 시 연관 매핑 초기화 가능)
5. 쿼리에서 해당 ID 값(0 등)을 필터링하는 조건이 있는지 확인
