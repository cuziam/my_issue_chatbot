## 조사 시 체크포인트
1. AlertConfig.fromCDO() 메서드에서 alert_type이 CDO에서 동적으로 읽어오는지 확인
2. AlertConfigCDO에 alertType 필드와 getter가 정의되어 있는지 확인
3. 알람 이력 DB에서 alert_type 값이 실제 알람 유형과 일치하는지 조회
4. pktWasStat.java의 thread_dump/use_script 실행 조건이 alert_type.equals("Stat Alert")로 되어 있어, 타입 수정 시 TP Stat Alert에서 해당 기능 동작 변경 가능성 확인
5. AlertEnv.java의 알람 타입 상수(ALERT_TYPE_STAT_ALERT, ALERT_TYPE_TP_STAT_ALERT 등)와 DB 저장값 대조
