## 공통 패턴

## 조사 시 체크포인트
1. 스캐터 차트의 색상 판단 로직이 `exception` 필드를 사용하는지, `elapse` 부호를 사용하는지 확인
2. RTM 스캐터(XMTxnMonitorChart.js)는 `exceptionType` 기반으로 정상 동작 — PA 스캐터(D3ScatterSelectable.js)만 문제
3. 그리드 목록의 예외 표시(ResponseInspector.js)는 별도 렌더러로 정상 동작하므로, 차트와 그리드 간 불일치 여부 확인
4. elapse가 0 또는 음수(-0)인 트랜잭션의 DB 레코드(`xapm_class_method_exception`)에서 exception 필드 확인
