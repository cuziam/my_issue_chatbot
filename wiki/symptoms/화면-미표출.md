## 조사 시 체크포인트
1. 브라우저 F12 Console에서 `SyntaxError: Unexpected token` 에러가 있는지 확인
2. view.html (RTM/PA/Config) 내 `<script>` 블록 안에 `<img>`, `<div>` 등 HTML 태그가 혼입되어 있지 않은지 확인
3. 패치 적용 후 화면 미표출이면 원본 view.html과 라인 수 비교 (불필요한 코드 혼입 여부 판단)
4. 이미지 경로 404 에러로 인한 화면 미표출과 JS 문법 에러로 인한 미표출을 구분 (Network 탭 vs Console 탭)
5. `<img id='initImg'>` 태그가 `<body>` 직하위에 정상 위치하는지 확인 (로딩 화면 표시 + JS에서 `$('#initImg').hide()` 참조)
