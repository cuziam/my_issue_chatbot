## 조사 시 체크포인트
1. 에이전트명에 특수문자(괄호, 공백, 쿼테이션 등)가 포함되어 있는지 확인
2. 브라우저 Console에서 `Comm.selectedWasArr` 값이 UI 선택 상태와 일치하는지 확인
3. Application > Local Storage에서 `InterMax_PopUp_Param`의 `wasId` 값 확인
4. 동일 창 이름(`hide_referrer_1`) 재사용으로 이전 팝업 파라미터 잔존 여부 확인
5. 괄호 없는 일반 에이전트명으로 동일 테스트 수행하여 특수문자 기인 여부 판별
