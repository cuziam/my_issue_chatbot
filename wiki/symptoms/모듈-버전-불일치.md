## 관련 키워드

|------|--------|----------|------|--------------|----------|
| IMX-9383 | 신세계포인트 | mod_imx (nginx) | nginx 1.28.1 / setup_imxmod_nginx_2507.01 | nginx .so 모듈이 1.28.0용으로 빌드되어 1.28.1에서 버전 검증 실패 (`version 1028000 instead of 1028001`) | C 네이티브 모듈 (코드베이스 외) |

## 공통 패턴

## 조사 시 체크포인트
1. nginx 버전 확인: `nginx -v`로 정확한 major.minor.patch 확인
2. 설치 패키지 unpack 후 `imx_mod/` 디렉토리에서 해당 nginx 버전과 **정확히** 일치하는 .so 파일 존재 여부 확인
3. nginx 버전 번호 체계: `major * 1,000,000 + minor * 1,000 + patch` — patch 버전이 1이라도 다르면 모듈 로드 거부됨
4. 에러 메시지 패턴: `[emerg] module "..." is not binary compatible ... version XXXXXXX instead of XXXXXXX`
5. 새 nginx 버전이 릴리스될 때마다 해당 버전용 .so를 별도 빌드해야 함 — 연구소에 빌드 요청 필요
