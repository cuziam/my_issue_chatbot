## 공통 패턴
우리투자증권 APIM 환경에서 2건 연속 발생. 공유 메모리 미생성(IMX-9564)과 공유 메모리 구조체 손상(IMX-9577) 모두 imxosm → DataGather 데이터 전송 실패로 귀결. C 네이티브 데몬과 Java DataGather 간 구조체 크기 일치가 필수적이며, strcpy 대신 strncpy 사용으로 버퍼 오버플로우 방지 필요.

## 조사 시 체크포인트
1. `imxapimadmin -c`로 공유 메모리가 생성되었는지 확인 (`ipcs -m`으로 SHMKEY 세그먼트 존재 확인)
2. 기동 순서 확인: `imxapimadmin -c` → `imxosm -D` → `imxtxn -D` → 업무 프로세스
3. 커널 파라미터(`shmmax`, `shmall`) 값이 필요 메모리 크기보다 큰지 확인 (`imxapimcal`로 계산)
4. SHMPERM 설정 확인: imxosm과 업무 프로세스가 다른 사용자로 실행되면 0666 권장 (기본 0644는 소유자만 rw)
5. `IMXAPIM_HOME` 환경변수와 `LD_LIBRARY_PATH`가 올바르게 설정되었는지 확인
