## 조사 시 체크포인트
1. 새 에이전트 타입이 추가되었을 때, monitorType별 분기(if-else/switch) 코드에 해당 타입이 포함되어 있는지 확인
2. `collectAgentListByMonitorType` 등 에이전트 분류 함수에서 새 타입이 별도로 분류되는지 확인
3. `rtmMultipleMonitorTypeTxnMonitor.js`의 `componentClassByMonitorType` 매핑에 새 타입이 등록되어 있는지 확인
4. 해당 타입 전용 컴포넌트(예: `rtmLOGTransactionMonitor`)가 이미 구현되어 있으나 연결만 안 된 경우가 많음
5. AGENT 목록에서 해당 타입에 미지원 기능(예: 액티브 트랜잭션) 버튼이 비활성화 처리되어 있는지 확인
