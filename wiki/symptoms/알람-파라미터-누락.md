SMS adaptor, guid NULL, 알람 파라미터 누락, SMSData, EtoE Alert, SMS 연계 데이터 누락, info.guid, 알람 필드 누락, smsAdaptor guid

| IMX-9582 | 농협경제 | DataGather | 5.3 (Build 231212.11) | TcpReadAlarmHistory에서 Exception Alert 분기의 SMSData 생성자가 guid 없는 13개 파라미터 버전을 호출하여 guid=null 전달 | TcpReadAlarmHistory.java:154-155, SMSData.java:39,114 |

## 조사 시 체크포인트
1. SMS adaptor 로그에서 `info.guid` 값이 NULL인지 확인
2. TcpReadAlarmHistory.java에서 Alert 유형별 SMSData 생성자 호출 분기 확인 (Exception Alert, Elapsed Time Alert, OOM Alert 등)
3. SMSData 생성자 오버로드 확인 — guid 포함 버전(16개 파라미터)과 미포함 버전(13개 파라미터) 구분
4. 동일 트랜잭션의 GUID가 InterMax 웹 UI 예외 화면에서는 정상 표시되는지 확인 (GUID 자체 수집은 정상이고 전달 경로에서 누락인지 판별)
5. req.guid에 값이 정상 파싱되었는지 DataGather 로그 확인
