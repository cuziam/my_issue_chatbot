## 조사 시 체크포인트
1. 조회 함수에 중복 호출 방지 플래그(loading guard)가 있는지 확인
2. 비동기 API를 복수 동시 호출하는 경우, 모든 응답 완료 후 플래그를 해제하는지 확인
3. 콜백에서 기존 데이터 clearRows 후 addRow 하는지, 또는 누적 추가(append)인지 확인
4. 조회 버튼 UI disable/enable 처리가 있는지 확인
