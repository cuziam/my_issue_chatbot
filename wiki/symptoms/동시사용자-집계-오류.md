## 조사 시 체크포인트
1. `jspd.prop.ini`에서 `USE_SESSIONID_FOR_WEBID` 값 확인 (false여야 쿠키 기반 집계)
2. `DISABLE_WEBID` 값 확인 (기본값이 true이므로 반드시 false로 명시 필요)
3. `ENABLE_WEB_ID_WHEN_NO_USERAGENT` 값 확인 (비브라우저 요청 시 webId 생성 여부)
4. JSPD 로그에서 "Use Cookie" vs "Use Session" 출력 확인
5. 브라우저 개발자 도구에서 `_xm_webid_1_` 쿠키 생성 여부 확인
6. 앱 내장 브라우저(WebView/Edge 엔진)의 쿠키 지원 여부 확인
7. `touch jspd.home`으로 설정 동적 리로드 후 변경 적용 확인
