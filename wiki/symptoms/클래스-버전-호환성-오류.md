# 클래스 버전 호환성 오류

## 관련 키워드
UnsupportedClassVersionError, bad major version, class version, JVMCFRE003, JDK 버전 불일치, 클래스 로딩 실패, ext 클래스, 컴파일 버전

## 과거 사례
| 이슈 | 고객사 | 컴포넌트 | 버전 | 근본 원인 요약 | 핵심 파일 |
|------|--------|----------|------|--------------|----------|
| IMX-9689 | ABL생명 | JSPD | Agent 25.09.12.03 | jspd.jar 내장 ext 클래스가 JDK 1.7+로 컴파일되어 IBM JDK 1.6 런타임에서 UnsupportedClassVersionError 발생, HTTP 트랜잭션 자동 연계 불가 | com/exem/jspd/e/a.java (ext 로딩), build-ext/build.xml |

## 공통 패턴

## 조사 시 체크포인트
1. 런타임 JDK 버전 확인 (IBM JDK 1.6 등 레거시 환경 여부)
2. `javap -verbose {클래스}.class`로 class file major version 확인 (50=1.6, 51=1.7, 52=1.8)
3. jspd-ext.jar가 별도 배치되어 있는지 확인 (`{JSPD_HOME}/lib/jspd-ext*.jar`)
4. 에이전트 로그에서 `class not found` 또는 `UnsupportedClassVersionError` 메시지 검색
5. build-ext/build.xml의 `target`/`source` 설정과 JAVA_HOME/JAVA_VERSION 환경변수 확인
