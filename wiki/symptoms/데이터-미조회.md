## 공통 패턴
DB에 데이터가 존재하지만 UI에서 표시되지 않는 경우, 조회 SQL/API의 필터 조건이 데이터와 불일치하는 것이 근본 원인. (1) JOIN 조건 불일치: INNER JOIN 참조 테이블에서 레코드 삭제 시 조회 누락 (2) 컬럼 필터 불일치: 스키마 변경(컬럼 추가)으로 신규 필터 조건이 추가되었으나 기존/이관 데이터에 해당 값이 없어 필터에서 제외

## 조사 시 체크포인트
1. 조회 SQL에서 INNER JOIN으로 참조하는 테이블 중, 삭제/비활성 시 레코드가 제거되는 테이블이 있는지 확인
2. xapm_was_info, xapm_server_info 등 메타 테이블이 alive 상태의 Agent만 포함하는지 확인
3. WAS/Agent 삭제 시 동작하는 DB function/trigger가 관련 메타 테이블을 cascade 삭제하는지 확인
4. xapm_pool_state 등 시계열(팩트) 테이블에는 데이터가 남아있는지 직접 DB 조회로 확인
5. 동일 Agent의 다른 탭(에이전트 지표 등)에서는 데이터가 표시되는지 비교 확인
6. v5.4에서 ServerNameCacheStore + LEFT JOIN으로 수정된 패턴이 적용되었는지 확인
7. 버전 업그레이드/마이그레이션 시 새로 추가된 컬럼(TYPE, STATUS 등)이 INSERT문에 포함되어 있는지 확인
8. UI 조회 API에서 신규 필터 조건(WHERE TYPE = ?)이 추가되었는지, 기존 데이터가 해당 조건을 만족하는지 확인
