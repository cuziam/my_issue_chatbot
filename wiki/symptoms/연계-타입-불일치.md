## 공통 패턴

## 조사 시 체크포인트
1. InterMax 내부 타입명(CDM, LOG 등)과 외부 연계 제품이 사용하는 타입명(CD 등)이 일치하는지 확인
2. DataModule.js의 타입 정규화 로직(CDM→CD, LOG→logIdArr 등)이 연계 API 응답에도 적용되는지 확인
3. 연계 제품의 지원 타입 목록에 InterMax 원본 타입과 변환 타입 양쪽 모두 포함되는지 확인
4. 에이전트가 서비스에 올바르게 매핑되어 있는지 확인 (특히 LOG 타입은 별도 서비스 매핑 필요)
5. LinkedManager.js의 showResponseInspector()에 해당 타입의 뷰가 등록되어 있는지 확인
