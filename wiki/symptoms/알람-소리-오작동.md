## 조사 시 체크포인트
1. 알람 소리 설정 확인: 내 설정 > 알람 설정에서 어떤 레벨이 체크되어 있는지
2. 알람 로그에서 실제 alert level 값 확인 (Warning=1, Critical=2)
3. WebSocket 패킷(ws?product=mfj&Alarm)에서 전달되는 alert_level 확인
4. 소리 필터 조건 확인: bootAlarms 목록, alertType, description, isHistorySend
5. 수집서버 재시작/모듈 기동 시 자동 생성되는 시스템 알람(Gather Disconnected, Server Down 등)의 alert level 확인
6. WAS 인스턴스 수에 따른 알람 발생 건수 확인 (대량 알람 시 소리 지속 시간 증가)
