## 조사 시 체크포인트
1. OS의 LANG 환경변수 확인 (`locale | grep LANG` → `ko_KR.UTF-8` 여부)
2. JVM `file.encoding` 시스템 프로퍼티 확인 (`-Dfile.encoding=UTF-8` 지정 여부)
3. SQL 파일/properties 파일을 읽는 코드에서 `FileReader` 사용 시 charset 명시 여부 확인
4. `InsertExecutor.java`처럼 `StandardCharsets.UTF_8`을 명시한 코드와 비교
5. 깨짐이 발생한 테이블(XAPM_OPTION_PROPERTY 등)을 TRUNCATE 후 UTF-8로 재삽입하여 복구 가능 여부 확인
6. 패치 적용 시 Install Repository 실행 여부 및 실행 환경의 인코딩 설정 확인
