## 공통 패턴

## 조사 시 체크포인트
1. 에러 발생 시점에 브라우저 Console에서 `self.wasField.AllWasList` 배열 내용 확인 → 해당 에이전트 ID 포함 여부
2. 페이지 로딩 후 충분히 대기(10초+)한 뒤 첫 조회 시 에러 재현 여부 확인 (미재현=타이밍 이슈 확정)
3. RTM 화면을 먼저 충분히 로딩한 후 PA로 전환하면 에러 미발생 여부 확인
4. Auto Scale 에이전트가 아닌 일반 에이전트에서도 발생하는지 확인
5. `Comm.oldServerInfo` 로딩 완료 시점과 `AllWasList` 구성 시점 간 순서 확인
